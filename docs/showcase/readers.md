# 初見の読者の答え

二人の読者（Claude）に、設定資料を渡さず、序章と第一章、第二章の二つの版だけを読ませた。どちらがハーネスを通した版かは伏せ、X・Y という名前で渡した。X が after（`after/02.kym.txt`）、Y が before（`before/02.kym.txt`）。読む順の偏りを消すため、読者 A は X から、読者 B は Y から読んだ。

答えは、読者の返事を見出しと箇条だけ整えて載せている。

## 点数

| | 読者 A: Y | 読者 A: X | 読者 B: Y | 読者 B: X |
| --- | --- | --- | --- | --- |
| 続きを読みたい度（1〜5） | 3 | 4 | 3 | 4 |
| 人物が生きて感じられたか（1〜5） | 3 | 4 | 3 | 4 |
| 第一章からのつながり（1〜5） | 3 | 4 | 3 | 5 |
| 読み続けたい版 | | X | | X |

## 読者 A（X → Y の順）

### X

- 続きを読みたい度 4。刻印の点の位置から「崖の下、ふだんは海の中」までつながり、三日後に何をしに行くかが具体的に分かる。
- 引っかかった所
  - 「ポケットから鍵を出して並べてみると、本当に同じ模様だな。」地の文の途中で急に独り言の口調になり、だれの声か一瞬迷った。
  - 「師匠の前では形無しだな、と可笑しくなった瞬間、ばあちゃんの目が右手で止まって、からかう色がすっと引いた。」一文に詰めこみすぎで、二度読んだ。
  - 「波の幅がほとんど同じじゃないか」十年なぞってきた模様なのに、今になって気づくのが都合よく見える。
- 良かった所
  - 「せいぜい六割だよ」→「最近は七割は越えてるもん！」祖母と孫の関係が一往復で分かり、最後の「六割なんて言わせないから」にも効いている。
  - 打ち明ける場面の間（「一秒、二秒。鍵の角が手のひらに食いこむ。」）。第一章の「笑わないよ」を回収していて、緊張が伝わる。

### Y

- 続きを読みたい度 3。祖母の証言で謎は動くが、刻印は「灯台だった」で止まり、次に探すものが増えない。
- 引っかかった所
  - 「あの霧の濃い朝かい」「あんた、あの日に海を見たのかい」序章では鍵を拾った朝と船を見た朝は別の日なのに、同じ日として話が進む。
  - 「アオバんちのソラくん」初めて出る名字に説明がなく、一瞬だれのことか分からなかった。
  - 「すべてが、岬の先へ戻っていく。」「今度こそ何かが動く気がした。」読めば分かることを地の文がまとめ直していて、締めが平板。
- 良かった所
  - 「一番下の線だけが途中でわずかに浅くなっているところまで同じだった」模様が同じだと納得できる細部。
  - 「また八割か？」「今度は九割。……たぶん」第一章の「たぶん」の掛け合いを自然に繰り返している。

### 選んだ版: X

- 刻印の点が「海の側」を指し、ハルの潮読みが「大潮で崖下が出る」につながって、謎と特技が一本の線になる。
- 祖母がからかいとはぐらかしの両方で生きていて、打ち明ける場面に重みがある。
- Y は読みやすいが手がかりが増えないため、三日後への期待が弱い。

## 読者 B（Y → X の順）

### Y

- 続きを読みたい度 3。ばあちゃんが船を見たと認めて手がかりが繋がるのは心地よいが、章の終わりまで予想どおりに進み、驚きが少ない。
- 引っかかった所
  - 「昨日、灯台の裏でさぼってた人が言わないで」第一章で灯台の裏にいたのは霧の前の日なので、この章の時点では一昨日になる。
  - 「ハルが振り返ったときには、勝手口はもう閉まっていた」重要な話の途中で、ばあちゃんが黙って消える。わざとなのか書き落としなのかが分からない。
  - 「鍵穴の目印じゃなかったんだね」何を「目印」と言っているのかがつかめない。刻印の発見が、戸を引いたら見えたという偶然に頼っていて、鍵が役に立っていない。
- 良かった所
  - 「一番下の線だけが途中でわずかに浅くなっているところまで同じだった」照合の細かさに説得力がある。
  - 「今度は九割。……たぶん」第一章の「たぶん」と八割を受けていて、ハルらしい。

### X

- 続きを読みたい度 4。ばあちゃんが何かを隠している気配と、三日後の大潮という具体的な期限があり、進路の紙で日常の側も引っぱっている。
- 引っかかった所
  - 「昨日は霧の中、灯台の根元を坂側から一周しただけで〜今日ここへ来た」冒頭の経緯の説明が一段落に詰めこまれていて重い。
  - 「本当に同じ模様だな。」「波の幅がほとんど同じじゃないか。」地の文が急に独り言の口調になり、一瞬つまずいた。
  - 「小さな点は、その波の側、塔の足もとに打ちこまれていた」点の初出が唐突で、位置関係を一度読んだだけでは描けなかった。
- 良かった所
  - 「せいぜい六割だよ」「ちがうし、最近は七割は越えてるもん！」第一章の八割を使った笑いで、祖母と孫の関係が一瞬で分かる。
  - 「鍵の持ち手を、板戸の波の上にそっと当ててみる」鍵の模様そのものが仕掛けを開く。十年なぞってきた指の記憶が生きている。

### 選んだ版: X

- 鍵の模様で板がずれる仕掛け、潮が引いた崖の下という場所、期限の理由がそろっていて、謎が一歩進んだ実感がある。
- ばあちゃんがはぐらかすことと、ソラが話すのをためらうことで、人物に陰影がある。
- Y は滑らかだが、説明で進む場面が多く、引きが弱い。
