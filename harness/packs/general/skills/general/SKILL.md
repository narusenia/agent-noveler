# 汎用

ジャンルを決めない最小の文体パック。書き方は役の手順書と作品の `AGENTS.md`・`style/` に従い、このスキルは目安と lint だけを持つ。

## 書き方の目安

- 視点は作品で固定する。視点人物が知らないこと、見えないものを地の文に書かない。
- 設定を講義しない。新しい情報は一場面に一つまで、筋に効く出来事は人づての報告で済ませない。
- 会話は生きた話し言葉にする。一言の応酬が続く所、全員同じ温度の所、台詞の意味を念押しする地の文を避ける。
- 感情は山場で声と体に出す。感情の名前を段落の終わりに置いて締めない。
- 文の長さに緩急をつける。lint の数字に合わせて文を刻まない。
- 作者が気に入った文（作品の `style/keep.md`）は、どの作業でも変えない。

## lint

`syuki lint <章>`（syuki の無い作品では `uv run --offline .agents/skills/general/scripts/check_style.py <章>`）。中身は light-novel パックの `check_style.py` を共有している。

- 指摘は目安。読みやすさとぶつかったら読みやすさを取る（`.agents/rules/prose-tools.md`）。
- 「声なし」（語り手の話し声のない地の文が続く区間）は、語り手の声を立てる作品のための指摘。三人称の抑えた語りなら、作品の `style/profile.toml` に `voice_min = 0` と書いて止める。
