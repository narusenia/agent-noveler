# AI 文の癖

AI が書く小説の文に出やすい癖の一覧。執筆の前に読み、推敲で照らす。「lint」の列は `check_style.py` の種別名で、空欄のものは目で見る（[check.md](check.md) の「判断の項目」）。根拠の番号は [sources.md](sources.md)。

癖を消すことが目的ではない。消した所は空けたままにせず、その場の具体的な声・動作・物で書き直す。山場で感情を声と体で出すことは、癖ではない。

## リズム

| 癖 | 悪い例 | 良い例 | lint | 根拠 |
| --- | --- | --- | --- | --- |
| 文の長さが揃う | 二十字前後の文が五つ六つ並ぶ | 長い描写の文のあとに短い決めを一つ | 文長 | P3, P17 |
| 細切れで深さを装う | 夜だった。静かだった。椎名はいない。それだけ。 | 屋上に椎名の姿はなく、野球部のライトが一台ずつ消えていく音だけがした。 | 細切れ | O5 |
| 段落末の決め台詞 | 段落ごとに「それが、答えだった。」で着地する | 段落の終わりを動作か次の出来事にする。決めは場面に一つ | | O5 |
| 前振りのあと一語で落とす | 前の段落を受けて「二人ぶん。いつもどおりだ。」「俺も、歩いた。」と短い段落で落とす。「出てきたのは、〜だった。」 | 前の段落につなぐ（「俺も歩いた。坂を下りると〜」）。落としは章に三つまで、効く所だけ | 落とし | O5 |
| 文末が揃う | 〜た。〜た。〜た。〜た。 | 描写・状態・内言の文をル形にする（「〜ている」「〜だ」） | 文末 | P20 |
| 段落の重さが揃う | 台詞と一、二文の段落だけが何頁も続き、情景も山も同じ速さで過ぎる | 場面の入りと厚く書く所に、情景・体・間を置く百字前後の段落を一つ。ほかは薄く流す（[rhythm.md](rhythm.md)「段落と場面の波」） | 平ら | |
| 同じ書き出しが続く | 俺は〜。俺は〜。俺は〜。 | 主語を落とす、語順を入れ替える、前の文とつなぐ | 文頭 | O1 |

## 読点

| 癖 | 悪い例 | 良い例 | lint | 根拠 |
| --- | --- | --- | --- | --- |
| 「〜は、」の機械的な読点 | 椎名は、袋を差し出した。 | 椎名は袋を差し出した。 | 読点 | P1, P4 |
| 台詞の短い語のあとの読点 | 「俺、今、全部、食べた」 | 「俺もう全部食べたって」 | 台詞の読点 | P4 |
| 息継ぎで打つ地の文の読点 | 西日が、机の列を、斜めに切った。 | 西日が机の列を斜めに切った。 | 読点 | P18 |

- 地の文の読点は、長い修飾語の境目と、語順を逆にした所に打つ [P18]。
- 台詞の読点は、息継ぎ・言いよどみ・話し始めの間（「でも、」「いや、」「え、あ……」）にだけ打つ。区切って話すのが口調の型の人物は、`profile.toml` の `comma_exempt` に書いて外す。

## 語彙

| 癖 | 悪い例 | 良い例 | lint | 根拠 |
| --- | --- | --- | --- | --- |
| 体の反応の決まり文句 | 息を呑んだ、心臓が早鐘を打つ、背筋に冷たいものが走った | その場で体に起きたことを一つ（「袋を持つ手が止まった」） | 決まり文句 | P11, P15, O2 |
| 表情の決まり文句 | 口元に笑みを浮かべた、眉をひそめた、瞳が揺れた | 何をして、それが何に当たったか（「笑いをこらえて鼻が鳴った」） | 決まり文句 | O2 |
| 情景の決まり文句 | 静寂が辺りを包んだ、空気が張り詰めた、夕日が長い影を落とす | その場所にしかない音か物（「ライトが消える音がバコン、バコンと遠くなる」） | 決まり文句 | O2, O3 |
| 時間の省略の決まり文句 | 永遠にも思えた、日々が過ぎていった | 何が何回あったか（「三回目の味見で、ようやく歯が勝った」） | 決まり文句 | O2 |
| 締めの決まり文句 | 今はそれで十分だった、二人なら大丈夫だ、もう元には戻れない | 未解決を一つ残して切る | 決まり文句 | O2, P10 |
| 大げさな言い換え | ただのクッキーじゃない。想いの結晶だった。 | 焦げたクッキーだった。三回作り直した跡が袋の底に溜まっていた。 | 決まり文句 | W11 |
| つながりを温度で言う | 温もりが胸に広がった、温かい空気が二人を包む | 何をしてくれたかを書く | 決まり文句 | W11 |
| 無生物主語と「物語る」 | その笑顔が全てを物語っていた | 笑顔の中身を書く（「歯を見せて、目だけ笑っていなかった」） | 決まり文句 | O1 |
| 英語小説の直訳 | 沈黙が答えだった、その重みを感じた | 英語に訳し戻して英語の定型なら書き直す | 決まり文句 | O1, O2 |
| 呼び替え | 一度「紙袋」と書いた物を次に「包み」と呼ぶ | 一度付けた名前で呼び続ける | | O1 |
| 語の組み合わせのずれ | 沈黙を破棄する、期待を遂行する | ふだんの会話で言うかで確かめる。和語を漢語に置き換えた所を疑う | | O1, P11 |
| 美文 | 黄昏が世界を茜色に染め上げ、二人の影を永遠に繋ぎ止めた | 視点人物が見て言える言葉にする | | P11 |

決まり文句は1話に1回までなら残してよい。2回目からは書き直す。作品で出すぎる語は `style/cliches.txt` に足す（数えれば見つかる [P14][P15]）。

## 口癖

AI は人物の口癖を、場面ごとに入れたがる。口癖を言わせるだけで人物を立てると、人物が口癖の束に見える。

| 癖 | 悪い例 | 良い例 | lint | 根拠 |
| --- | --- | --- | --- | --- |
| 口癖を毎場面入れる | 椎名が三場面続けて「見ればわかるでしょ」で締める | 一章に1〜2回、効く所だけ | 口癖 | |
| 口癖で場面を閉じる | 「……見ればわかるでしょ」で場面が終わる | 口癖のあとに、どんな気持ちで言ったかが見える反応を一つ | | |
| 山場でも口癖 | 告白の返事が口癖 | 山場では口癖を外し、その人の言葉で言わせる | | |

- 口癖は人物ファイルの「- 口癖:」と `profile.toml` の `[catchphrases]` に書く。lint は章ごとに数え、`catchphrase_limit`（既定2）を超えたら指摘する。
- 語尾（「〜のね」「〜だろ」）は口癖に数えない。

## 説明しすぎ

AI の文で直されることが多く、しかも減りにくい [P11]。

| 癖 | 悪い例 | 良い例 | lint | 根拠 |
| --- | --- | --- | --- | --- |
| 台詞のあとの言い直し | 「別に」と彼女は言った。本当は別にではなかった。 | 受け手の動作か次の台詞で受ける | | P11 |
| 念押しの地の文 | それ以上は言わなかった。手も、抜かなかった。 | 起きたことを一つ書く | 打ち消し | P11 |
| 描写の直後の再要約 | 手が震え、声がかすれた。怖かったのだ。 | 要約の文を消す | 感情ラベル | O7 |
| 自問して「よくわからない」 | なぜ笑ったのだろう。照れか、それとも。よくわからない。 | 視点人物が気づいた一点だけを書く | | W12 |
| 打ち消しの報告が続く | 答えなかった。訊かなかった。見なかった。 | 黙っている間の体を書く | 打ち消し | |
| 語り手の声が消える | 廊下を歩いた。扉の前で足が止まった。返事はなかった。俺は部屋に戻った。（報告が続く） | 一文をツッコミかボヤキにする（「まあ、そうなるよな」） | 声なし | 研究文書 第3部2 |
| テーマを地の文で言う | 大切なのは、言葉にすることなのだと思った。 | 人物の選択で見せる。迷いを残してよい | | W13 |

## 構成

| 癖 | 悪い例 | 良い例 | 根拠 |
| --- | --- | --- | --- |
| すぐ丸く収める | 喧嘩した場面の終わりで、もう和解している | 未解決のまま次の場面へ持ち越す | P10 |
| 筋が一本道 | 障害が一つ出て、一つ解ける、を繰り返す | 選択に代償をつける。下降と上昇を二度 | P9, P25, W13 |
| 最初の案 | AI が最初に出した展開やギャグをそのまま使う | 最初の案を捨て、二つ目以降から選ぶ。作者の指定を優先する | P8, P9, P27 |
| 積み上げのない変化 | 一場面で人物の考えが変わる | 変わる前に、揺らぐ出来事を二つ置く | O4 |
| 話に合わない明るい結末 | 代償を払った巻が、全員の笑顔で終わる | 失ったものを最後の場面にも残す | O4, P10 |

## 記号と体裁

| 癖 | 悪い例 | 良い例 | lint | 根拠 |
| --- | --- | --- | --- | --- |
| 文をつなぐ「……」 | 「それは……その……クッキー……」 | 本当に詰まる所だけ。一つの台詞に一つ | | W11 |
| 太字・見出し・絵文字 | `**彼女は笑った**` | 本文に記法を残さない | 記号 | W11 |
| 半角スペース、“” | 「OK だよ」、“特別” | 全角の記号に揃える | | W11 |
| 記号で勢いを出す | 「！！！」「！？！？」 | 文章で勢いを出す。「！」は叫ぶ所で一つ | | W4 |

## 確かめ方

lint で拾えない癖は、手を動かして確かめる [O1]。

- 英語に訳し戻す。訳した文が英語小説の定型（"Silence was the answer." など）なら書き直す。
- ふだんの会話で言うか、声に出して確かめる。言わない語の組み合わせは、AI には自然に見える。
- 名詞で終わる文を動詞の文に直してみる。誰が何をしたかが消えていたら直す。
- 台詞から名前と地の文を抜いて、誰の台詞か当てられるか確かめる（[check.md](check.md) の盲検）。
- AI に AI の文を採点させない。評価は専門家と相関しない [P12]。上の具体的な項目で照らす。
