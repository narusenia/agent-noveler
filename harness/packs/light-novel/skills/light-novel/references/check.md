# 文体チェック

ラノベらしい日本語か、AI臭くないかを検査する。本文は書き換えない。違反を箇所つきで返す。直すのは「直して」と頼まれたときだけで、手順は [fix.md](fix.md)。

## 手順

1. 機械チェックを実行する。パスはこのスキルのディレクトリ基準。

   ```bash
   uv run scripts/check_style.py 本文.md
   ```

   本文がファイルに無いときは標準入力で渡す。初回は uv が SudachiPy と辞書を取得する。uv が使えないときは下の「機械チェックの項目」を目で見る。
   作品の `style/profile.toml` があれば、リズムの型、口癖、作品の決まり文句の辞書を読む。場面ごとに型が違うときは `--rhythm 軽快` のように渡す（[rhythm.md](rhythm.md)）。
2. 出力の違反を採る。誤検出は理由を1行添えて外す。例: 山場で意図した長文、キャラの口癖としての定型。`・判断` の付いた指摘は違反ではない。下の「判断の指摘」で扱う。
3. 「判断の項目」を本文で確かめる。
4. 「返す形」で返す。

## 機械チェックの項目

| 種別 | 見るもの |
| --- | --- |
| 冒頭 | 天気、目覚め、通学路で始まる |
| 章末 | 「こうして」「一日が終わった」の要約締め |
| 感情ラベル | 悲しかった、緊張していた、で段落が終わる |
| 文末 | 地の文の文末2字が3連続 |
| 句点 | 閉じ括弧前の句点 |
| 比喩 | 1場面で3つ目、または段落を比喩で締める |
| 長文 | 地の文の1文が60字超 |
| 説明 | 地の文の1段落が200字超 |
| 細切れ | 会話を挟まずに、20字未満の地の文が6文続く |
| の連続 | AのBのCのD |
| 記号 | 本文中の太字記法、絵文字。♪♡★ などの記号は拾わない |
| 決まり文句 | `data/cliches.txt` と作品の `style/cliches.txt` の語句が、一章の上限を超えた（[ai-tells.md](ai-tells.md)） |
| 文長 | 地の文の5文が同じくらいの長さで揃う。章全体の平均文長、一文段落の割合、文長のばらつきが型の目安から外れる |
| 読点 | 「〇〇は、」で始まる地の文が章の8%を超える |
| 文末（章全体） | 地の文の8割超が「〜た。」で終わる |
| 文頭 | 地の文が同じ書き出し（「俺は」「彼女は」）で3文続く |
| 打ち消し | 地の文の5文に「〜なかった。」が3つ |
| 台詞の読点・判断 | 台詞で、主語・指示語・短い副詞のすぐあとに読点（「俺、」「それは、」「今、」）。列挙と言いよどみは数えない |
| 人称・判断 | 作品の profile.toml の `[pov]` があるとき。三人称限定では、台詞の直後に入口なしで心の声に入り同じ段落で外の描写に戻る段落と、同じ段落で視点人物の名前と一人称が混ざる所。一人称では、地の文で視点人物の名前が主語になる所。序章や幕間など視点の違う章は `exclude` で外す |
| 口癖・判断 | 人物ファイルの「- 口癖:」と profile.toml の口癖が、一章の上限（既定2回）を超えた |
| 落とし・判断 | 前振りのあと一語で落とす型が一章の上限（既定3つ、profile.toml の `drop_limit`）を超えた。数えるのは、25字以上の地の文の段落のすぐあとの12字以下の段落（ツッコミと倒置は除く）、読点のあと短い一語で終える13字以下の文（「俺も、歩いた。」）、分裂文「〜のは、〜だった。」。該当の行番号を並べて一件で出す |
| 平ら・判断 | 百字以上の地の文の段落（`thick`）を挟まずに、本文（地の文と会話）が二千字（`flat_gap`）を超えて続く区間を一件ずつ。＊と見出しで切る。薄く流してよい区間（ドタバタ、会話の応酬の山）なら残す（[rhythm.md](rhythm.md)「段落と場面の波」） |
| 短い場面・判断 | ＊で区切った場面が八百字（`scene_min`）未満。＊のない章は見ない。幕切れの短い場面として狙ったなら残す |
| 声なし・判断 | 一人称の語り手の声（話し言葉の型）がない地の文が `voice_run` 文以上続く区間（声ありが一文ずつ、四文に一つまで挟まってもよい。会話・見出し・作中の文書で切る）を一件ずつ。章全体の声ありの割合が `voice_min` 未満なら一件。声ありとみなすのは、終助詞か言いさし（けど・し・から）で終わる、倒置（「効くな、これ」）、「だろ」「じゃない」、縮約（てる・ちゃう・とく・〜んだ）、「って」、意志形、非過去の「だ」か形容詞の言い切り、「？」「！」、感動詞か「まあ」「で、」「なんか」「いや」で始まる文。既定は 10 文と 30%、profile.toml の `voice_run`・`voice_min` で変える。会話と山場で静かにした所は誤検出になる |

最後の行に型、会話比率、地の文の平均文長、文長のばらつき、一文段落の割合、違反と判断の件数が出る。目安は型ごとに [rhythm.md](rhythm.md) にある。数値は目安で、違反0は目指さない。

閾値は作者の既刊のラノベ3巻分で測って決めた（2026-10-19）。その本文は「〇〇は、」が章の9〜20%、平均文長17〜25字で、作者が細切れと読点の多さを直したいと言っていた所と合う。

## 判断の指摘

口調にかかわる指摘（台詞の読点、口癖、盲検で外れた台詞）は、ガチガチに守ると台詞の表現が痩せる。違反にせず、判断の材料として出す。終了コードにも数えない。

- 一件ずつ、意図があるかを見る。間を聞かせたい読点、山場で型が崩れた台詞、天丼として重ねた口癖は残す。
- 自分で決められるものは決め、残したものは理由を1行で返す。
- 作品の決まりと食い違う、どちらにも読める、作者の好みに関わるものは、まとめて作者に聞く。聞き方は [fix.md](fix.md)「判断の指摘」。
- 区切って話すのが型の人物は、profile.toml の `[comma_exempt] speakers` に書く。話者が地の文にある台詞（「と椎名が言った」）と、`--speakers 答え.json` で話者を渡した台詞は、読点を数えない。

## 盲検

台詞を名前なしで区別できるかを確かめる。AI に文章の良し悪しを採点させても当てにならない [P12]（[sources.md](sources.md)） ので、点数ではなく「話者を当てられるか」という具体の課題にする。

1. `uv run scripts/voice_check.py sheet 本文.txt > 台詞.txt` で、地の文を抜いた台詞の表を作る。
2. 本文を読める側（書き手か checker）が、行番号ごとの話者を `答え.json`（`{"42": "椎名"}`）に書く。syuki の作品では `style/speakers/<巻>/<章>.json` に置く（`syuki style endings` が読む）。
3. 本文を読んでいない別のエージェントに、`台詞.txt` と人物ファイル（口調サンプル）だけを渡し、同じ形で `推定.json` を書かせる。
4. `uv run scripts/voice_check.py report 本文.txt --answers 答え.json --guesses 推定.json` で、外れた台詞、取り違えの多い組、人物ごとの一人称と語尾の分布を見る。
5. 外れた台詞は判断の指摘として扱う。短い相づち（「うん」「は？」）は誰が言っても外れるので、外れても直さない。

`答え.json` は `check_style.py --speakers` にも渡せる。

## 判断の項目

| 項目 | 合格 | 要修正の例 |
| --- | --- | --- |
| テンポ | 地の文が動作、感覚、情景で進み、文の長短に緩急がある | 説明や回想で場面が止まる。短文と一行段落が続いて細切れになる |
| 情景と戦闘 | 場面の入りと山場で、場所と人の配置が見える。戦闘に動きの順序と手応えがある | どこで誰が何をしているか分からない。戦闘が一行の繰り返しで終わる |
| 一人称の地の文 | 視点人物の語彙と温度で書かれている | 誰が語っても同じ地の文 |
| 人称の揺れ | 心の声へ動作か知覚から入り、外の描写に戻るときは段落を分けている（[style.md](style.md)「視点」） | 台詞の直後に急に心の声になる。同じ段落で語りと心の声を出入りする。三人称の段落に「俺」、一人称の段落に視点人物の名前 |
| 口調 | 話者タグを外しても誰か分かる（盲検で確かめる） | 全員が同じ丁寧さ、同じ語尾。口癖を言わせて人物を立てている |
| 掛け合い | 会話がキャラの関係やズレを見せる | 情報の受け渡しだけの会話 |
| 会話の生気 | 台詞の長さに幅があり、相手の言葉に反応し、人物ごとに温度が違う | 短い一言の応酬が続く、全員が同じ静かさ、「……」始まりが多い、台詞の意味を直後の地の文で念押しする |
| 感情の山 | 山場とその前後で、感情が声と体で外に出る。章に一度は温度が上がりきる | 喧嘩や別れや告白が淡々と流れる、「〜なかった。」の打ち消しで反応を報告する、「少しだけ」で山場を包む |
| 見せる | 感情を動作と会話で出す | 感情の名前で説明する。台詞のあとで地の文が意味や感情を言い直す |
| 繰り返し | 比喩、決まり文句、口癖、場面の締め方が章の中で重ならない | 同じ比喩や締めの型が何度も出る。段落末が毎回決め台詞 |
| 笑いと温度 | 章の温度が plot の配分に合い、落差の前に笑いがある（[comedy.md](comedy.md)） | 笑いの説明、重い出来事の直後のギャグ、喧嘩をすぐ和解に丸める |
| 説明 | 設定は選択を縛る場面でだけ、1場面に1つ出る。筋に効く出来事は場面か台詞で見せる | 設定の講義、説明台詞、1場面に新しい情報が集中する、筋に効く出来事を人づての報告で済ませる、推量の「らしい」の連発 |
| AI臭さ | 具体的な物と動作で書かれている | 「静寂が辺りを包んだ」のような誰でも書ける美文、同じ構造の対句、三つ並べの列挙、段落ごとの要約、「本当の戦いが始まろうとしていた」のような予告調の締め |
| 冒頭と章末 | 冒頭でジャンル、視点人物、欠落、フックが読める。章末に未解決が1つ | 世界観の講義で始まる、解決して終わる |

## 返す形

```text
- [文末] 13行目: 地の文の文末「いた」が3連続。1つ変える。
- [テンポ] 15〜17行目: 設定説明で場面が止まっている。主人公の選択に絡む一文だけ残す。

判定
- テンポ: 要修正（15〜17行目）
- 一人称の地の文: 合格
- 口調: 合格
- 掛け合い: 要修正（19〜24行目）
- 見せる: 合格
- 説明: 要修正（15行目）
- AI臭さ: 要修正（5, 9, 19行目）
- 冒頭と章末: 要修正（3, 23行目）

会話比率 14% / 地の文の平均文長 24.6字
```

返すのは違反一覧、判定、統計の3つだけで、この順に並べる。違反は機械チェックと判断の項目を行順に混ぜる。修正案は1違反につき1行まで。点数は付けない。

前置き、統計の後の講評や補足は付けない。会話比率が目安から外れていても、統計の行に数字を出すだけにする。上の例のコードブロックは形を示すためのもので、返すときは囲まない。
