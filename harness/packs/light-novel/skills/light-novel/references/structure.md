# 構成

## 順序

本文より先に、次の順で固定する。

1. ログライン1行。誰が、何を失いまたは欲し、何に阻まれ、何をする話か。
2. 一行コンセプト。売り。例: 魔王が時給で働く。
3. 結末。最終的に何が残り、何が失われるか。
4. クライマックス。結末を確定させる場面。
5. あらすじ800字以内。結末まで書く。内部用プロットは4000字まで。
6. 話ビート。各話の目的、章末フック、温度（笑い:シリアス）。下の「温度の曲線」。
7. 場面カード。

結末が無い状態で本文を書かない。

## 比率

目安であり、契約ではない。

- 起承転結: 起10 / 承40 / 転40 / 結10
- 序破急: 序10 / 破80 / 急10

中盤が説明で膨らんだら、選択を迫る障害に置き換える。

## 場面カード

1シーン1ブロック。本文に混ぜない。空欄があるシーンは書かない。

```text
- 視点人物:
- 場所・時刻:
- 目的（視点人物がこの場で欲しいもの）:
- 入口の圧:
- 障害:
- 結果（成功 / 失敗 / 代償）:
- 状態変化（情報・関係・身体のどれが変わったか）:
- 出口の未解決:
- 新しく出す情報: （1つまで。無ければ「なし」）
- 伏せること（回収する場面）: （無ければ「なし」）
- 守る既出事実:
- リズム: （空欄なら作品の既定。緩急 / 軽快 / 描写 / 饒舌）
- 温度: （笑い:シリアス。例 7:3）
- 字数と拍: （例: 約三千字、拍5つ）
- 厚く書く所: （一つ。何で滞在するか: 情景 / 体 / 会話の往復 / 間）
- 薄く流す所: （要約で済ませる拍。無ければ「なし」）
- 入りと出: （入りの足場の一段落に置くもの / 出で受ける一拍）
```

- 「リズム」は作品の既定（`style/profile.toml` の `rhythm`）と違う型で書く場面だけ埋める。型は [rhythm.md](rhythm.md)。
- 「新しく出す情報」は、この場面で読者が初めて知る設定・用語・事情。1場面に1つまで。2つ目が要るなら、それが選択か会話に効く場面へ回すか、場面を分ける。出し方は [style.md](style.md)「説明」。
- 「伏せること」は、この場面で匂わせるが明かさないことと、明かす場面（例: 伏せる: 帳面の噂が本当か（第4章 図書館の地下））。回収の場面のカードの「新しく出す情報」と対にする。
- 「字数と拍」「厚く書く所」「薄く流す所」「入りと出」は、場面の重さの差を決める欄。拍の数の目安は下の「濃淡と配分」、書き方は [rhythm.md](rhythm.md)「段落と場面の波」。
- 「温度」は話ビートの章の温度に沿わせる。落差の直前の場面は笑いを厚く、落差の場面はシリアスに振り切る（[comedy.md](comedy.md)）。

## 濃淡と配分

「新しく出す情報は1つ」を守っても、一場面に運ぶものが多いと、どれも数行ずつで過ぎて急ぎに読める。カードの段階で総量と重さの差を決める。

- 運ぶもの（説明、伏線、初登場、決め台詞、笑いの山、関係の一段）は、一場面に主なもの二つまで。ほかは薄く流すか、別の場面へ回す。
- 拍（カードの中身の一項目、「a. 〜」）は、場面の字数を拍の数で割って五百字を下回らない（三千字なら六つまで）。下回ったら、拍を削る、薄く流す所へ回す、場面を分ける、後の章へ回す、のどれか。
- 厚く書く所は一場面に一つ、字数の四割前後。章の山の場面では、それが山そのものになる。書き方は [rhythm.md](rhythm.md)「段落と場面の波」。
- 場面の字数を揃えない。章に一つ長い場面（章の字数の三割以上）を置き、ほかは短めにする。八百字未満の場面は幕切れなど狙いがあるときだけ。
- 場面の入りと出に一拍ずつ字数を見込む。転換のたびに、場所・時刻・持ち越した気持ちを渡す足場の一段落が要る。場面を増やすほど、この分が削られて急ぎになる。
- 一場面で何日も流すときは、流す日々を薄く、残す一日を厚くする。

## 温度の曲線

巻の笑いとシリアスの配分を、話ビートに書く。

1. 作品の既定比率を `style/profile.toml` の `balance` に書く（例: 笑い 6 / シリアス 4）。
2. クライマックスの章をシリアスに振る（例 2:8）。
3. その直前の章で落差の前振りを置く（例 5:5）。前振りの章の最後の場面は笑いを厚くする。
4. 序盤は既定より笑いを多くし、結の章は笑いで戻す。
5. 巻の中で下降と上昇が2回以上あるか確かめる。右肩上がりだけ、下がりっぱなしだけにしない。
6. シリアスが2章続いたら、次の章に笑いの場面を一つ置く。

```text
- 第1話: 目的 / 章末フック / 温度 8:2
- 第2話: 目的 / 章末フック / 温度 7:3
- 第3話: 目的 / 章末フック / 温度 5:5（落差の前振り）
- 第4話: 目的 / 章末フック / 温度 2:8（山場）
- 第5話: 目的 / 章末フック / 温度 6:4（緩和で戻す）
```

心情だけのシーンは禁止。変化が無いシーンは削除する。

## 章

- 1章は場面カード2〜4枚を目安にする。5枚以上にするときは、各場面の拍と入り・出の字数が足りるかを「濃淡と配分」で確かめる。
- 章末フックは、未解決の問い、危機、意外な一言、選択の未決のどれか1つ。
- 伏線は仕込み時に回収予定の話をメモする。未回収のまま終えない。
- 回想は短く、現在へ戻す合図を置く。

## 冒頭

最初の場面で、ジャンル、視点人物、欠落、フックの4つが読めること。世界観の講義で始めない。
