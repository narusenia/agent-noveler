# 会話文の悪い例と良い例

[style.md](style.md) の「会話」「感情」「戦闘」と、[comedy.md](comedy.md) の見本。人物の口調の型は作品ごとに違うので、型ではなく直し方を真似る。作品の本文から作った見本は、作品フォルダの `style/dialogue-examples.md` に置く。

見本の好み: 地の文は緩急型（[rhythm.md](rhythm.md)）、会話は言いさしと噛み合わなさのある話し言葉、笑いは地の文のツッコミ、シリアスへは落差で切り替える。

## 1. 甘い場面（短い応酬 → 生きた話し言葉）

悪い例:

```text
「味見して」
「……わかった」
　俺はクッキーを一枚取って、口に入れた。
「どう？」
「硬い」
「そう」
　椎名は少し俯いた。
「でも、うまい」
　椎名は顔を上げた。その頬は、わずかに赤く染まっていた。
　胸の奥が、温かくなった。
```

良い例:

```text
「味見。して」
「いや、するけど。……これ、何？」
「クッキー！　見ればわかるでしょ」
　見てもわからないから訊いたんだが。
　一枚つまむと、指先にざらっと黒い粉がついた。覚悟を決めて齧る。がり、と歯の奥で鳴った。
「どう？」
「どうって……いや、味は、うん。砂糖の味はする」
「それ褒めてないよね？」
「褒めてる褒めてる。ただ、その、外側がちょっと……硬いというか」
「そこは食感だから！」
「食感なのかよ。歯が負けたぞ今」
　椎名は袋の口をぎゅっと握って、俺の顔を下からにらんだ。にらんでいるのに、耳だけ赤い。
「……じゃあ、もう食べなくていい」
「食べるって。まだ二枚目だろ」
　二枚目も硬かった。三枚目で、焦げていない端っこに当たって、普通にうまかった。言ったら調子に乗るので、黙って四枚目に手を伸ばした。
```

何を変えたか:

- 台詞の長さに幅。言いさし（「その、外側がちょっと……」）、言い直し（「硬いというか」）。一語の返事を続けない。
- 相手の言葉に反応させる。「砂糖の味はする」に「それ褒めてないよね？」。噛み合わなさが会話らしさになる。
- 地の文のツッコミで笑いを確定させる（「見てもわからないから訊いたんだが。」）。ボケを説明しない。
- 感情の名前（温かくなった、頬が赤く染まった）を使わない。にらんでいるのに耳だけ赤い、黙って四枚目に手を伸ばす、で見せる。
- 甘さは、隠す仕草と行動で出す。「うまい」と言わせずに、四枚目に手を伸ばさせる。

## 2. 落差（笑いの最中にシリアスへ）

悪い例:

```text
「食感なのかよ」
「ふふっ。……あのね、実は話があるの」
　椎名の表情が、急に真剣なものに変わった。
「私、来月、転校するんだ」
　その言葉は、まるで冷たい水のように俺の心に染み込んだ。
　俺は言葉を失った。
「そっか……寂しくなるな」
「うん。でも、離れていても、ずっと友達だよね」
「当たり前だろ」
　二人は笑い合った。夕日が二人の影を長く伸ばしていた。
```

良い例:

```text
「食感なのかよ。歯が負けたぞ今」
「……そっか。じゃあ、もう一回だけ練習できたらよかったな」
　笑うと思った。いつもならここで「うるさい」が飛んでくる。
「私、来月、引っ越すんだ」
　口の中の焦げた砂糖が、急に味をなくした。
「……は？　え、来月って、来月？」
「来月って来月だよ。ほかに何があるの」
「いや、だって、文化祭」
「出られない。ごめん」
　謝られた。椎名に謝られたのは、たぶん初めてだ。
　何か言わなきゃいけないのに、口の中にまだクッキーが残っていて、噛むと、がり、とさっきと同じ音がした。
```

何を変えたか:

- 切り替えの合図を「来るはずの返しが来ない」にした。予告の台詞（「実は話があるの」）と「表情が真剣に変わった」を消した。
- 切り替えた直後は比喩を抜き、具体的な物で受ける（口の中の砂糖が味をなくす）。
- 主人公をうろたえさせる（「来月って、来月？」）。言葉を失ったと書かず、言葉にならない台詞を書く。
- すぐ和解やまとめ（「ずっと友達だよね」「笑い合った」）で閉じない。未解決のまま、さっきと同じ音で場面を残す。
- 笑いの道具（硬いクッキー）を、シリアスの側で別の意味に変える。

## 3. 喧嘩と涙（淡々 → 声と体で出す）

悪い例:

```text
「どうして言ってくれなかったんだよ」
「言えなかったの」
「なんで」
「……ごめん」
　椎名は俯いた。その目には、涙が浮かんでいた。
　俺は、それ以上は何も言わなかった。
```

良い例:

```text
「なんで今まで黙ってたんだよ。先月から決まってたんだろ」
「言ったら、あんた、変な顔するじゃん」
「するに決まってるだろ！」
　声が廊下まで響いて、自分で驚いた。椎名の肩がびくっと跳ねる。
「……ほら。してる。今、その顔」
「どんな顔だよ」
「わかんないよ！　わかんないけど、それ見たくなかったの！　最後まで普通に、焦げたクッキー食べさせて、普通に怒られて、それで――」
　最後のほうは声になっていなかった。椎名は紙袋を胸に押しつけて、ずるずるとしゃがみこんだ。袋の中で、クッキーがかしゃかしゃ鳴った。
```

何を変えたか:

- 一語の応酬（「なんで」「……ごめん」）を、理由のある長い台詞にした。人物ごとに温度を変え、主人公が先に怒鳴る。
- ヒロインを泣かせる。泣くことを地の文で報告せず、声が崩れていく台詞と、しゃがみこむ体で見せる。
- 「！」は叫ぶ所で使う。
- 念押しの地の文（「それ以上は何も言わなかった」）を消し、袋の中のクッキーの音で場面を残す。

## 4. 戦闘（説明の連続 → 掛け合いと焦りと衝撃）

悪い例:

```text
　大男が斧を振り上げた。ミナは剣を構えたまま、動かなかった。斧が振り下ろされると、ミナは横へ一歩ずれてそれを避けた。斧が地面を割り、破片が飛んだ。破片がミナの頬をかすめ、血が流れた。
「遅いわね」
　ミナは前へ出て、剣で男の腕を斬った。男は後ろへ下がった。
　周囲からどよめきが上がった。
　俺は、その間ずっと男の手元を見ていた。
```

良い例:

```text
「上だ、ミナ！」
　言い終わる前に、斧はもう落ちはじめていた。
　ミナは刃の軌道を最後まで目で追って、右足を半歩引いただけだった。
　がん、と石畳が鳴って、割れた欠片が膝の高さまで跳ねた。一つがミナの頬に赤い線を引いた。
　今の、避けたのか。たまたま外れただけじゃないのか。
「遅いわね」
「……っ、見てるこっちの寿命が縮むんだけど」
「じゃあ目をつぶってなさい。ここからもっと縮むから」
　返事を待たずに、ミナは踏みこんだ。
　下がるのではなく、男の懐へ。斧を振り上げきる前の、腕のいちばん内側に肩から潜りこんでいく。刃が前髪を何本か持っていき、下から振り上げた剣が男の籠手の留め金を打った。
　浅い。それでも男は、ここへ来て初めて一歩下がった。
「やるじゃねえか、姉ちゃん！」
　見物の人垣から野太い声がかかり、あちこちで口笛が続いた。
　俺の耳には入っていなかった。男の左手が、腰の短剣の柄にかかっている。ミナの側からは見えない位置だ。
```

何を変えたか:

- 戦いの最中に掛け合いを入れる（「見てるこっちの寿命が縮むんだけど」「じゃあ目をつぶってなさい」）。強がりと焦りの温度差が盛り上がりになる。
- 視点人物の焦りを地の文の心の声で見せる（「今の、避けたのか」）。見ているだけの役にも、気づく役を与える。
- 説明はつないで長く、衝撃は短く音と体で書く（「がん、と石畳が鳴って」）。
- 観客の声を台詞にする（「やるじゃねえか、姉ちゃん！」）。「どよめきが上がった」で済ませない。
- 場面の終わりを解決にせず、次の危機（見えない側の短剣）で切る。

## 5. やってはいけない型（一覧）

| 型 | 例 | 直し方 |
| --- | --- | --- |
| 一言の応酬が続く | 「来た」「言わない」「後でな」 | 一つは長くし、言いさしや聞き返しを入れる |
| 全員同じ温度 | 誰の台詞も「……」で始まり読点で刻む | 人物ごとに口調と感情の出方を変える |
| 気の利いた返しで閉じる | 「食感だから」「便利な言葉だな」で場面が終わる | 返しのあとに、照れ・苛立ち・笑いなどの反応を一つ置く |
| 念押しの地の文 | 「同じ言葉だった」「それ以上は言わなかった」 | 削る。受け手の動作か次の台詞で受ける |
| 打ち消しの報告 | 「答えなかった」「訊かなかった」が続く | 起きたことを書く。黙るなら、黙っている間の体を書く |
| 感情を小さくする | 「少しだけ」「一度だけ」で山場を包む | 山場では外す。声と体で出し切る |
| ご褒美を隠す | 「笑ったのかどうか、見えなかった」 | 意図がなければ、見える形で見せる |
| 口癖で締める | 場面の最後の台詞がいつも同じ口癖 | 一章に1〜2回。山場では外す |
| 主語のあとの読点 | 「椎名は、答えなかった」 | 溜めが要る所だけに残す |
| 台詞の短い語のあとの読点 | 「俺、今、全部、食べた」 | 息継ぎと言いよどみの所だけに打つ |
| 予告してから切り替える | 「実は話があるの」で空気を変える | 来るはずの返しが来ない、で切り替える |
