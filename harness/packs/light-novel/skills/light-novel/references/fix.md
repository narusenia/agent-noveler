# 文体の修正

推敲で「直して」「書き換えて」「AI臭さを消して」と頼まれたときの手順。文体チェックの違反を、筋を変えずに最小限で直す。「チェックして」だけの依頼では使わない。

## 手順

パスはこのスキルのディレクトリ基準。本文がファイルに無いときは、作業ディレクトリに書き出してから始める。

0. 作品の `style/keep.md`（作者が残すと決めた文）を読む。ここにある文は、どの手順でも変えない。
1. 元の本文を控える。`本文.md` を作品フォルダの外の一時ディレクトリに `元.md` として複写する。作品フォルダに控えを残さない。
2. 機械的に直せる違反を直す。

   ```bash
   uv run scripts/check_style.py --fix --json 本文.md
   ```

   句点と記号だけが直り、本文に書き戻る。残りの違反が `findings` に、行番号と該当箇所（`match`）つきで出る。
3. 残った違反を「直し方」の表に沿って直す。直すのは違反のある文だけ。前後の文は触らない。
4. `check.md` の「判断の項目」で要修正のものも直す。機械チェックを通った文も見る。予告調の締め（「本当の戦いが始まろうとしていた」）、段落ごとの要約、誰でも書ける美文はAI臭さとして消すか、具体的な物と動作に置き換える。口調は `characters.md` に口調サンプルがあるときだけ直す。
5. 再検査する。

   ```bash
   uv run scripts/check_style.py --baseline 元.md 本文.md
   ```

   次のすべてを満たせば終わる。満たさないときは 3 に戻る。3〜5 は3回まで。
   - 残った違反が、「直し方」の表で「直さず報告する」と決めたものだけ
   - 「新規」が「なし」。違反は種別と該当箇所の組で突き合わせるので、同じ種別でも別の箇所に出たものは新規に数え、行番号が付く
   - セリフの変更が無いか、口調サンプルに合わせて語尾を変えたものだけ
   - 字数に「要確認」が付いていない
   - 「残す文」が出ていない（keep.md の文が消えた、変わった）。出たら元に戻す
   - `・判断` の指摘は条件に入れない。下の「判断の指摘」で扱う

   残す違反が無く、セリフも変えていなければ、終了コードは 0 になる。
6. 「返す形」で返し、`元.md` を消す。

Python が使えないときは 2 と 5 を `check.md` の「機械チェックの項目」と下の「変えないもの」を目で見て行う。

## 直し方

| 種別 | 直し方 | 直さず報告するとき |
| --- | --- | --- |
| 句点 | スクリプトが直す | なし |
| 記号 | スクリプトが直す | なし |
| 決まり文句 | 上限を超えた分を、その場の動作か物に置き換える。上限内は残してよい。推量の「らしい」と人づての見出しは、[exposition-examples.md](exposition-examples.md) の別の言い方に回し、同じ直し方を続けない | キャラの口癖。台詞の中の人づて（人物が噂を話す） |
| 文長 | 揃った5文のうち、一つを前とつなぐか、一つを短く切る。章全体の目安は、型を見直すか場面ごとに緩急をつける | 型どおりの意図した揃え（列挙、反復の効果） |
| 読点 | 「〇〇は、」の読点を取る。取ると読みにくい長い主語のときだけ残す | 長い修飾語の境目の読点 |
| 文頭 | 2文目か3文目の主語を省くか、語順を変える。体言止めや疑問形で散らさない | 意図した反復 |
| 打ち消し | 「〜なかった。」の一つを、起きたことの文にする | 否定が出来事そのもの（来なかった、など） |
| 感情ラベル | 段落末の感情語の文を、身体か動作の文に置き換える | なし |
| 文末 | 3連続目だけ変える。前の文とつなぐ、語順の入れ替え、現在形のどれか。体言止めで散らさない | なし |
| 細切れ | 短い文をつないで一文にするか、情景や動きの具体を一つ足す。一文だけの段落は前後の段落に寄せる | 山場で意図した決めの一拍 |
| 比喩 | 3つ目の比喩は消す。段落の締めの比喩は消すか、事実か動作にする | なし |
| 長文 | 2文に割る | 山場で意図した長文 |
| 説明 | 設定の説明なら、選択を縛る分だけ残して会話か動作に割る。1場面に新しい情報が2つ以上あるときは、残す1つを決め、ほかは回す先の場面の案を報告する（[style.md](style.md)「説明」） | 情景や戦闘の描写で長いとき、削ると既出事実が消えるとき。筋に効く出来事を人づてで済ませているときは、場面を足すことになるので直さず報告する |
| の連続 | 語順を変えるか、「にある」や読点で切る | なし |
| 冒頭 | 天気や目覚めの文を後ろに回し、セリフかフックの文を先頭に出す | 本文にフックになる文が無い |
| 章末 | 要約の文を消し、その前の未解決で切る | 消すと未解決が残らない |

置き換えの例。

| 種別 | 直す前 | 直した後 |
| --- | --- | --- |
| 決まり文句 | 「ねえ、聞いて」ユイの声に、俺は再び息を呑んだ。 | 「ねえ、聞いて」ユイの声に、俺は振り返った。 |
| 読点 | 椎名は、袋の口を折り返した。 | 椎名は袋の口を折り返した。 |
| 感情ラベル | 俺は嬉しかった。 | 俺は布団を蹴って起き上がった。 |
| 文末 | 考えていた。空を見ていた。ユイのことを思っていた。 | 考えていた。空を見ていた。頭にあるのはユイのことばかりだ。 |
| 比喩 | 青空が広がっていた。まるで今日を祝福しているかのようだった。 | 青空が広がっていた。 |
| の連続 | 王都の学園の中庭の噴水の前で | 王都にある学園の中庭、噴水の前で |
| 章末 | （最終行）こうして、俺たちの新しい一日が終わった。 | （その行を消し、前の未解決で切る） |

## 判断の指摘

`・判断` の付いた指摘（台詞の読点、口癖、人称）と盲検で外れた台詞は、口調と語りの表現にかかわる。人称の指摘を直すときは、心の声の前に視点人物の動作か知覚を一つ置くか、段落を分ける（[style.md](style.md)「視点」）。決まりで機械的に直すと台詞が痩せるので、次の順で扱う。

1. 一件ずつ、意図があるかを見る。間を聞かせたい読点、山場で崩れた口調、天丼の口癖、区切って話す型の人物の台詞は残す。
2. 自分で決められるものは決める。残したものは「残した」に理由を1行で書く。
3. 決められないもの（作品の決まりと食い違う、どちらにも読める、作者の好みに関わる）は直さず、まとめて作者に聞く。AskUserQuestion が使えるときは一度に4問まで、おすすめを先頭に置き、直す前と直した後の台詞を見せる。使えないときは「作者に確認」に並べて返す。
4. 作者の答えで決まった型は、作品の profile.toml（`comma_exempt`、`catchphrases`）か人物ファイルに書き、次から同じことを聞かない。

声なしの区間は、ツッコミかボヤキを一つ入れるか、地の文を語り手の話し言葉に寄せる。語尾に「けど」を足すだけで消さない。山場で静かにした所は残す。

直す依頼でも、口調の型を作品の決まりより固く当てない。山場では型が崩れてよい。

## 気に入った所を残す

作者が「ここはいい」と言った文は、作品の `style/keep.md` に足す（書き方はファイルの先頭）。直したあとに `uv run scripts/check_style.py --baseline 元.md 本文.md` か `python3 scripts/keep_check.py --baseline 元.md 本文.md` を回すと、消えた文が出る。直す範囲を頼まれたときは、その外を触らない。

## 会話と感情を直す依頼のとき

「会話を自然にして」「淡々としすぎ」「感情を出して」のように頼まれたときは、上の表の最小修正ではなく、[style.md](style.md) の「会話」「感情」「戦闘」に沿って台詞と反応を書き直してよい。下の「変えないもの」のうち、セリフの中身と字数の上限はこの依頼では外れる。出来事の順序と結果、既出事実、記録済みの決め台詞、視点は変えない。

## 変えないもの

- 出来事の順序と結果
- 固有名詞、能力、時間などの既出事実。`plot.md` と `characters.md` があれば照らす
- セリフの中身。句点、！？、…は変えてよい。読点、中黒、ダッシュを変えると比較にセリフの変更として出る。口調サンプルに合わせて語尾を変えたときも出るので、1件ずつ語尾だけの変更か確かめる
- 視点と一人称
- 字数は元の±15%以内

作者が残すと決めた文（keep.md）を変えない。新しいキャラ、設定、出来事、比喩を足さない。外した決まり文句の代わりに、元に無い決め台詞を足さない（細切れを直すために、既にある場面の情景や動きの具体を足すのはよい）。直せない違反は書き換えで逃げず、報告する。違反を消すために文を短く刻んだり、描写を削ったりしない。

比較が見るセリフは、1行に収まった「」と『』の中身だけ。行をまたぐセリフは比較に出ないので、目で確かめる。

## 返す形

本文はファイルを上書きし、チャットには出さない。チャットには次だけを返す。

```text
直した: 7件（句点 1, 比喩 2, 感情ラベル 1, 文末 1, 決まり文句 1, 章末 1）
残した:
- [長文] 31行目: 山場の独白。意図した長文として残す。
- [台詞の読点・判断] 40行目: 「今、」は告白の前の間。残す。
作者に確認:
- [口癖・判断] 77行目: 三回目の「問題ない」。天丼として残すか、外して本人の言葉にするか。
- [冒頭] 3行目: フックになる文が本文に無い。場面の入りから見直す。
字数 3120 → 3015（-3%）/ セリフ変更なし
```

残した違反が無ければ「残した」の行は書かない。差分の解説、代替案、書き換えた理由は頼まれたときだけ出す。

前置き（「直しました」など）、締めの講評は付けない。上の例のコードブロックは形を示すためのもので、返すときは囲まない。
