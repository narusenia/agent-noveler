# 説明の悪い例と良い例

[style.md](style.md) の「説明」の見本。人物と設定は見本のための仮のもので、型ではなく直し方を真似る。作品の本文から作った見本は、作品フォルダの `style/exposition-examples.md` に置く。

良い例を一つの型に三つずつ置いているのは、一つの直し方に寄せると、それが新しい単調さになるから。同じ章で同じ直し方を続けない。

## 1. 推量の「らしい」（見たものを毎回「らしい」で受ける → 言い方を散らす）

視点人物は他人の内心や事情を断定できないので、「らしい」そのものは誤りではない。ただ、見たものを毎回「らしい」で受けると、語りが人づての報告に聞こえる。

悪い例:

```text
　部室の扉が開いて、椎名が入ってきた。走ってきたらしい。前髪が額に貼りついている。
　椎名は鞄を置くと、棚の前で立ち止まった。何か探しているらしい。
「ねえ、ここにあった赤いファイル」
　湊が昨日片づけたことには、気づいていないらしい。
```

良い例A（動作と様子だけを書き、推量は読者に任せる）:

```text
　部室の扉が開いて、椎名が入ってきた。前髪が額に貼りついて、肩で息をしている。
　鞄を床に落とすように置くと、椎名はまっすぐ棚へ行き、上の段から順に背表紙を指でなぞりはじめた。
「ねえ、ここにあった赤いファイル」
```

良い例B（視点人物の判断として言い切る）:

```text
　部室の扉が開いて、椎名が入ってきた。前髪が額に貼りついている。廊下を走ったな、と湊は思った。また生活指導に捕まるぞ。
　椎名は棚の前で止まり、上の段から背表紙をなぞりはじめた。探し物だ。しかも、こっちには心当たりがある。
「ねえ、ここにあった赤いファイル」
　昨日、湊が段ボールに詰めたやつだ。
```

良い例C（推量の言い方を変え、確かめたいことは台詞で訊かせる）:

```text
　部室の扉が開いて、椎名が入ってきた。前髪が額に貼りついているところを見ると、廊下を走ってきたのだろう。
　椎名は棚の前で止まり、背表紙を指でなぞった。
「何探してんの」
「赤いファイル。ここにあったやつ」
「ああ、それなら昨日――」
「捨てたの!?」
「捨ててない。まだ何も言ってない」
```

直した所:

- A は推量を消し、体の様子と動作だけを書く。走ってきたことも探し物も、読者が自分で気づく。
- B は視点人物の頭の中の言葉で言い切る。推量より語り手の温度が出る。
- C は「〜ところを見ると〜のだろう」に言い換え、残りは台詞で確かめる。確かめる掛け合いが、そのまま場面の笑いになる。
- 「らしい」を残すのは、視点人物が本当に確かめられず、確かめられないことが場面に効くときだけ。

## 2. 人づての要約（筋に効く出来事を又聞きで流す → 場面にする）

悪い例:

```text
　翌朝、部室に行くと、椎名が机に突っ伏していた。昨夜は徹夜で原稿を仕上げて、顧問に出したらしい。締め切りに間に合ったのは今年うちの部だけだった、と顧問が言っていたと、隣の部の部長から聞いた。
```

締め切りに間に合ったという、筋に効く出来事が、二重の人づてで流れている。誰も喜ばず、誰も驚かない。

良い例A（その場にいた人に、その場で言わせる）:

```text
　翌朝、部室に行くと、椎名が机に突っ伏していた。机の端に、表紙だけ赤ペンで直された原稿の控えがある。
「……出した」
　突っ伏したまま、椎名が言った。
「出したって、顧問に？　締め切り、昨日の五時だろ」
「四時五十八分」
　椎名は顔を上げないまま、指を二本立てた。勝ちの指なのか、ぎりぎりの指なのか分からない。
「間に合ったの、うちだけだって。先生、ちょっと引いてた」
```

良い例B（人づてで知る筋なら、知る瞬間を場面にする）:

```text
　椎名が原稿を間に合わせたことを、湊は隣の部の部長から聞いた。廊下ですれ違いざまに、肩を掴まれて。
「お前んとこ、どうなってんの。間に合ったの、お前らだけだぞ」
「は？」
「は？　じゃねえよ。顧問の机に一部だけ載ってた。赤い表紙の」
　赤い表紙。昨日の帰りに、椎名が鞄に押しこんでいたやつだ。
```

良い例C（物と結果を見せて、経緯は書かない）:

```text
　翌朝、部室の黒板の隅に、顧問の字で一行書き足されていた。
『提出　一部（文芸部のみ）』
　その下で、椎名が机に突っ伏して寝ていた。右手に、インクの切れたペンを握ったまま。
```

直した所:

- A は本人に言わせる。言い方（「四時五十八分」）に、徹夜の重さと得意さが乗る。
- B は人づてのまま、聞いた瞬間を場面にする。伝える人の驚きと、視点人物が気づく一拍が入る。
- C は黒板とペンだけで、提出と徹夜の両方を見せる。
- 人づての要約で済ませてよいのは、筋に効かない後日談だけ。「〜と言っていたと、〜から聞いた」の二重の人づては使わない。

## 3. 一度に説明する（設定を一段落に詰める → 1場面に1つ、半分だけ）

悪い例:

```text
　この学園には、生徒会とは別に「記録委員会」がある。創立当初からある組織で、学園で起きた出来事をすべて帳面に残すのが仕事だ。委員は五人だけで、委員長は代々、理事長が指名する。帳面は図書館の地下書庫にあって、委員のほかは読めない。そして、帳面に書かれたことは必ず本当になる、という噂がある。
```

一つの段落に、組織、仕事、人数、指名、保管場所、噂の六つが入っている。どれも、この場面の誰の選択にも効いていない。

良い例A（目の前の物から一つだけ出し、残りは問いにする）:

```text
　図書館の地下へ降りる階段には、鎖が一本渡してあった。札が下がっている。『記録委員会以外立入禁止』。
「記録委員会って何」
「知らない。見たことない」
　椎名は鎖を指で弾いた。ちゃり、と乾いた音がして、下の暗がりのどこかで、紙をめくる音が止んだ。
```

出したのは「委員会が地下にいる」だけ。仕事、人数、指名、噂は、それが選択に効く場面まで回す。

良い例B（選択を縛る一つを、掛け合いで出す）:

```text
「帳面に書かれたことは、本当になるんだって」
「誰がそんなこと」
「みんな言ってる。だから、委員長に名前を書かれたら終わり」
「終わりって、何が」
「知らない。終わった人に訊いて」
```

出したのは噂だけで、本当かどうかは伏せる。湊が帳面に近づくかどうかを縛る情報になる。

良い例C（人物の紹介を、名前と一つの動作で済ませる）:

悪い例:

```text
　隣の席の佐伯は、明るい茶髪に人懐っこい笑顔の男で、口の軽さは学年一だ。中学からの腐れ縁で、湊の秘密の半分はこいつ経由で漏れている。
```

良い例:

```text
　隣の席から、佐伯が椅子ごと寄ってきた。本人は声を潜めたつもりで、前の列の二人まで振り返らせた。
```

口の軽さは、声の大きさで一つだけ見せる。腐れ縁と秘密の話は、それが効く場面まで回す。

直した所:

- 新しい設定・用語・事情は、1場面に1つまで。
- 出すときは、名前か結果だけにする。理由や仕組みは後の場面で回収する。
- 説明役の独演にしない。訊く人と、答えきれない人の掛け合いにする。
- 人物の経歴と関係は、紹介の段落にまとめない。

## 例外: 山場の直前にまとめて出すとき

読者が状況を掴んでおかないと山場が読めないときだけ、まとめて出してよい。そのときも、掛け合いにして、聞き手に一度は止めさせる。

```text
「確認する。鍵は二本、片方は委員長が持ってる」
「もう片方は」
「帳面の中。……書いた人にしか取り出せない」
「待て。じゃあ誰が書いたんだよ」
「それを今から見に行くの」
```
