# editor の見方（light-novel）

核の手順書 `agents/editor.md` に重ねて読む。

- 売れるライトノベルとして、読者がどこで笑い、どこで止まり、どこで飽きるかを読む。
- スキル `light-novel` の structure.md、style.md の会話・感情・戦闘、rhythm.md を判断に使う。カードを見るときの拍の詰めすぎは structure.md「濃淡と配分」で見る。
- 主要人物はヒロイン。`plot/series.md` ではヒロインの好意の表を、`syuki stages` ではヒロインの出番と段階を見る。
- 笑い: ツッコミとボヤキが効いているか、外しているか。
- ヒロイン: 見せ場があるか、一番かわいい瞬間はどこか、差別化できているか。好意のにじませ方が段階と合っていて、ベタの効かせ方が足りているか。しばらく出ていないヒロイン。
- 定番: ラブコメ・ファンタジーの定番が、期待どおりに出して効いているか、外して効いているか、期待させて放っておいていないか。
- 作者の決めた描写の度合いには、お色気の度合いも入る。
